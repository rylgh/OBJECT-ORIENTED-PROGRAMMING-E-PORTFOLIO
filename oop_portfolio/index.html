06 / Learning Journal

Term Reflections

My learning experience in Object Oriented Programming.

Prelim Term Reflection

During the prelim term, I practiced the basics of Java programming. I learned how to use loops to repeat instructions, how arrays store multiple values, and how methods help organize code. The activities helped me understand how program instructions work step by step. I also learned that I need to practice more and check my code carefully, especially when solving problems involving conditions and loops.

Midterm Term Reflection

During the midterm term, I learned more about methods and the main ideas of object-oriented programming. Topics such as classes, constructors, access specifiers, and encapsulation helped me understand how Java programs can be organized. I also studied inheritance and abstract classes. The activities gave me practice applying these ideas instead of only memorizing their definitions.

Final Term Reflection

During the final term, I continued learning object-oriented programming through polymorphism and exception handling. I also worked on practical assessments, including a Product Information machine problem and GUI-related practice activities. These tasks helped me see how programming concepts can be used in a working application. I learned that debugging, reviewing instructions, and practicing are important parts of improving as a programmer.
