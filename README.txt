OBJECT ORIENTED PROGRAMMING E-PORTFOLIO

Files:
- index.html: Open this file in a browser to preview the portfolio.
- Object_Oriented_Programming_Activities.pdf: screenshots of the available lesson activities and assessment records.
- assets/: original screenshots used in the website.

The design uses a dark navy / cyan technology theme, intentionally different from the previous blush-pink Database Fundamentals portfolio.

To publish with GitHub Pages:
1. Create a NEW GitHub repository for this subject (do not use the ITC-C201 repository).
2. Upload index.html, the PDF, and the complete assets folder.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Open the Pages URL GitHub provides.

Some assessment scores were unavailable in the supplied screenshots. They are labeled as unavailable or submitted without a score; no scores have been guessed.
